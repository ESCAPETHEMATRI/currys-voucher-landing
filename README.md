# Currys voucher landing page

Static, responsive landing page based on the supplied reference. The **Claim Now** button opens the supplied affiliate offer URL. The page includes a visible independent-offer disclosure.

## Vercel

Import this repository into Vercel. Select **Other** as the framework preset and leave build and output settings blank; `index.html` is served from the repository root.

## Local preview

Open `index.html` in a browser, or run a static server in this directory.
